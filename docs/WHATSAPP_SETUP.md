# Настройка WhatsApp-бота (бесплатно, официальный способ)

Бот автоматически отвечает каждому, кто пишет на ваш WhatsApp-номер, а вам в
Telegram сразу приходит полное сообщение клиента со ссылкой «Открыть чат в
WhatsApp». Это официальный путь через Meta (WhatsApp Cloud API) — бесплатно
до 1000 разговоров в месяц, номер не банят, в отличие от неофициальных
библиотек.

Часть шагов — вход в ваш личный Facebook/Meta-аккаунт, их обязаны сделать
лично вы (я не могу входить в чужие аккаунты).

## 1. Создать приложение в Meta for Developers

1. Зайдите на [developers.facebook.com](https://developers.facebook.com/) под своим Facebook-аккаунтом.
2. «My Apps» → «Create App» → тип **Business**.
3. В приложении добавьте продукт **WhatsApp**.

## 2. Получить тестовые данные (бесплатно, без верификации бизнеса)

В разделе WhatsApp → **API Setup** вы сразу увидите:
- **Temporary access token** — это `WHATSAPP_ACCESS_TOKEN` (действует 24 часа, для теста хватит; постоянный токен — шаг 5).
- **Phone number ID** — это `WHATSAPP_PHONE_NUMBER_ID`.
- Тестовый номер WhatsApp от Meta (не ваш реальный) — им можно писать только с номеров, добавленных в **To** (разрешённые получатели), максимум 5 — добавьте туда свой личный номер, чтобы протестировать.

## 3. Придумать секрет для вебхука

`WHATSAPP_VERIFY_TOKEN` — любая случайная строка, которую вы сами придумываете (например, как пароль). Она нужна только для того, чтобы Meta подтвердила, что вебхук — ваш.

## 4. Заполнить .env.local и Vercel

```
WHATSAPP_ACCESS_TOKEN=токен_из_шага_2
WHATSAPP_PHONE_NUMBER_ID=id_из_шага_2
WHATSAPP_VERIFY_TOKEN=придуманная_строка
```

Те же три переменные нужно добавить в Vercel (Project → Settings →
Environment Variables) и передеплоить сайт.

## 5. Подключить вебхук в Meta

В приложении: WhatsApp → **Configuration** → Webhook:
- **Callback URL**: `https://ваш-домен/api/whatsapp/webhook`
- **Verify token**: то же значение, что в `WHATSAPP_VERIFY_TOKEN`
- Нажмите «Verify and Save» — если всё совпало, Meta подтвердит подписку.
- В списке полей подписки (Webhook fields) включите **messages**.

## 6. Проверить

С телефона из списка разрешённых получателей (шаг 2) напишите что-нибудь тестовому номеру WhatsApp. Вы должны получить:
- автоматический ответ в WhatsApp,
- уведомление в Telegram с текстом сообщения и ссылкой на чат.

## Когда захотите подключить свой настоящий номер

Тестовый номер от Meta подходит только для проверки (5 получателей). Чтобы
бот отвечал с вашего реального бизнес-номера всем клиентам:

1. В Meta Business Suite пройдите верификацию бизнеса (бесплатно, но проверка
   занимает от одного до нескольких дней).
2. Подключите свой номер телефона в WhatsApp → API Setup (номер должен быть
   свободен от привязки к обычному приложению WhatsApp — из него его нужно
   будет удалить).
3. Замените `WHATSAPP_ACCESS_TOKEN` на постоянный System User Token (в
   Business Settings → System Users) — временный токен истекает каждые 24 часа
   и для продакшена не годится.

# AutoFlash

Приложение для мастерской: подключается к автомобилю через OBD-адаптер (Bluetooth LE, Wi-Fi, USB/COM), само определяет авто, блоки управления и версии прошивок, ищет прошивки по модели и устанавливает пакеты прошивки в блок.

## Две вкладки

1. **Подключение.** Выбираете адаптер (Bluetooth / Wi-Fi / COM / демо) и подключаетесь. Автомобиль определяется сам, и в зоне «Подключённый автомобиль» видно: марка, модель, год, VIN, **через что именно подключены** (канал, устройство, чип адаптера, шина, напряжение), число блоков и ошибок.
2. **Авто и прошивки.** Подключённое авто и его блоки с доступными пакетами («Установить» / «Обновить» / «Актуально»), поиск по моделям (70 марок, 600+ моделей и поколений, по-русски и по-английски), подробная диагностика (блоки, ошибки, живые данные, отчёты) и библиотека пакетов прошивки.

## Установка прошивки по Bluetooth

Приложение передаёт прошивку из пакета (`.afpkg`, см. `docs/PACKAGE_FORMAT.md`) в блок по стандарту UDS: сессия программирования → доступ (SecurityAccess) → стирание → загрузка данных → проверка → перезапуск блока → сверка нового номера ПО. Перед записью читается резервная копия оригинала; при сбое предлагается вернуть её. Обновление: пакет с тем же `id` и более новой версией предлагается как «Обновить».

**Что для этого нужно:**
- адаптер на чипе **STN** (например OBDLink CX/MX+): обычные ELM327 не умеют отправлять длинные сообщения, приложение через них не прошивает и честно говорит об этом;
- пакет под конкретное семейство блоков с адресами, процедурой и алгоритмом ключа (его автор пакета добавляет в `SECURITY_ALGORITHMS`).

**Ограничения.** Скорость записи по Bluetooth низкая (порядка 2 КБ/с): прошивка в мегабайт займёт десятки минут, поэтому для крупных блоков лучше Wi-Fi или USB. Реальные блоки отличаются своими загрузчиками, и установка проверена только на виртуальном блоке.

## Чего приложение не делает

- Не содержит файлов прошивок: демо-пакеты ставятся только на виртуальный блок.
- Не включает позиции, отключающие системы очистки выхлопа.
- Нет общего облака: данные хранятся на этом компьютере (ежедневная копия в «Документы\AutoFlash\Backups»).
- Установщик без цифровой подписи: Windows может показать предупреждение SmartScreen.

## Настольное приложение (Windows)

```bash
npm run desktop:build                                          # сборка в desktop/out/AutoFlash-win32-x64
powershell -ExecutionPolicy Bypass -File desktop/install.ps1   # установка + ярлык на рабочем столе
npm run sim-server                                             # виртуальный Wi-Fi адаптер (STN) 127.0.0.1:35000
AutoFlash.exe --selftest=<папка>                               # самопроверка со скриншотами и report.json
npm test                                                       # автотесты ядра
```

Для Bluetooth и Wi-Fi на телефоне нужна dev-сборка (`expo-dev-client`).

## Устройство

- `src/core/` — вся логика без интерфейса: драйвер ELM327/STN, OBD-II, UDS, KWP, VIN, сканер, справочники авто и ошибок, пакеты прошивки, установка, симулятор.
- `src/transport/` — каналы связи (BLE, Wi-Fi, USB/COM, Web Bluetooth).
- `src/app/` — экраны (Expo Router); `desktop/` — оболочка Electron, сборка, самопроверка.
- `tests/` — автотесты на симуляторе.

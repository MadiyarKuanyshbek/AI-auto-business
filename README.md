# AutoFlash

Приложение для мастерской: подключается к автомобилю через OBD-адаптер (Bluetooth LE, Wi-Fi, USB/COM), само определяет авто, блоки управления и версии прошивок, ищет прошивки по модели, показывает, как будет выглядеть интерфейс экранов, и устанавливает пакеты прошивки в блок.

## Три вкладки

1. **Подключение.** Сверху два режима: «Реальный режим» (настоящие адаптеры и магнитолы, связь компьютера, реальный монитор) и «Демо-режим» (виртуальные автомобили с жёлтой пометкой, свой монитор). Они не смешиваются. Радар сам ищет рядом демо-автомобили, Wi‑Fi адаптеры OBD и магнитолы с открытым ADB; нажатие на найденное открывает окно с действиями (подключиться, установить приложения, русификация, прошивки). Блок «Связь компьютера» включает и выключает Bluetooth и Wi‑Fi компьютера (Windows), блок «Что происходит сейчас» показывает события и обмен с адаптером в реальном времени, а после подключения приложение само предлагает выбор: прошивки, интерфейс, приложения и русификация. Кнопки «Найти Bluetooth» и «COM / USB» добавляют устройства, а «Подключить вручную» оставляет прежний способ. Выбираете адаптер (Bluetooth / Wi-Fi / COM / демо) и подключаетесь. Автомобиль определяется сам, и в зоне «Подключённый автомобиль» видно: марка, модель, год, VIN, **через что именно подключены** (канал, устройство, чип адаптера, шина, напряжение), число блоков и ошибок.
2. **Авто и прошивки.** Подключённое авто и его блоки с доступными пакетами («Установить» / «Обновить» / «Актуально»), поиск по моделям (70 марок, 600+ моделей и поколений), подробная диагностика (блоки, ошибки, живые данные, отчёты, **глубокий поиск блоков** по всем адресам 0x700–0x7DF) и библиотека пакетов с **конструктором пакета из вашего файла**.
3. **Демо интерфейс авто.** По центру салон выбранной модели с экранами (приборная панель, центральный экран, проекция, подсветка). Справа поиск, выбор поколения и комплектации и файлы интерфейса: у каждого описано, что изменится на экране, под какой блок он и в каком состоянии (макет / файл готов / установлено). Выбор файла сразу перерисовывает салон. К модели можно прикрепить свои фото и ссылки на видео.

## Установка прошивки по Bluetooth

Приложение передаёт прошивку из пакета (`.afpkg`, см. `docs/PACKAGE_FORMAT.md`) в блок по стандарту UDS: сессия программирования → доступ (SecurityAccess) → стирание → загрузка данных → проверка → перезапуск блока → сверка нового номера ПО. Перед записью читается резервная копия оригинала; при сбое предлагается вернуть её. Обновление: пакет с тем же `id` и более новой версией предлагается как «Обновить». Интерфейсные файлы (темы панели и экранов) устанавливаются тем же механизмом.

**Что для этого нужно:**
- адаптер на чипе **STN** (например OBDLink CX/MX+): обычные ELM327 не умеют отправлять длинные сообщения, приложение через них не прошивает и честно говорит об этом;
- пакет под конкретное семейство блоков с адресами, процедурой и алгоритмом ключа (его автор пакета добавляет в `SECURITY_ALGORITHMS`).

**Ограничения.** Скорость записи по Bluetooth низкая (порядка 2 КБ/с): прошивка в мегабайт займёт десятки минут, поэтому для крупных блоков лучше Wi-Fi или USB. Реальные блоки отличаются своими загрузчиками, и установка проверена только на виртуальном блоке.

## Файлы интерфейса: что настоящее, а что макет

Для каждой модели и комплектации приложение показывает 12 файлов интерфейса (темы панели, анимация приветствия, подсветка, проекция). **Это макеты:** описание и превью есть, самих файлов пока нет, и они помечены «Макет». Состав экранов (цифровая или аналоговая панель, размер центрального экрана, HUD) определяется **ориентировочно** по марке, году и комплектации и может отличаться от конкретного автомобиля. Когда у вас появится настоящий файл, соберите из него пакет в конструкторе: он станет «Файл готов» и его можно установить.

## Приложения и русификация магнитолы (Wi-Fi)

В разделе «Авто и прошивки» есть кнопка «Приложения и русификация магнитолы (Wi-Fi)». Ноутбук подключается к магнитоле по Wi-Fi через ADB (Google platform-tools, `desktop/adb/adb.exe`, в репозиторий не входит: скачайте platform-tools с developer.android.com и положите `adb.exe`, `AdbWinApi.dll`, `AdbWinUsbApi.dll` в `desktop/adb/` перед сборкой). Можно ставить и удалять .apk, смотреть список приложений. Работает только там, где ADB открыт (Android-магнитолы, боксы, часть систем с включённым меню разработчика). **Проверено:** запуск adb и разбор ответов; **не проверено** на реальной магнитоле.

## Чего приложение не делает

- Не содержит файлов прошивок: демо-пакеты ставятся только на виртуальный блок.
- Не включает позиции, отключающие системы очистки выхлопа.
- Нет общего облака: данные хранятся на этом компьютере (ежедневная копия в «Документы\AutoFlash\Backups»).
- Установщик без цифровой подписи: Windows может показать предупреждение SmartScreen.

## Настольное приложение (Windows)

```bash
npm run desktop:build                                          # сборка в desktop/out/AutoFlash-win32-x64
powershell -ExecutionPolicy Bypass -File desktop/install.ps1   # установка + ярлык на рабочем столе
npm run sim-server                                             # виртуальный Wi-Fi адаптер (STN) 127.0.0.1:35000
AutoFlash.exe --selftest=<папка>                               # самопроверка со скриншотами и report.json
npm test                                                       # автотесты ядра
```

Для Bluetooth и Wi-Fi на телефоне нужна dev-сборка (`expo-dev-client`).

## Устройство

- `src/core/` — вся логика без интерфейса: драйвер ELM327/STN, OBD-II, UDS, KWP, VIN, сканер и глубокий поиск, справочники авто и ошибок, профили экранов и темы интерфейса, пакеты прошивки и конструктор, установка, симулятор.
- `src/transport/` — каналы связи (BLE, Wi-Fi, USB/COM, Web Bluetooth).
- `src/app/` — экраны (Expo Router); `src/ui/` — компоненты, включая `CabinPreview` (салон на SVG); `desktop/` — оболочка Electron, сборка, самопроверка.
- `tests/` — автотесты на симуляторе.

# Настройка админки (бесплатно)

Админка — страница `/admin` на сайте, закрытая паролем. Показывает две
таблицы: заявки с сайта и бизнесы, найденные через `fetch-leads-2gis.mjs` +
`score-leads.mjs --push`. Данные хранятся в **Postgres (Neon)** — бесплатная
база данных, подключённая напрямую через Vercel, без сторонних сервисов.

## 1. Пароль для входа

Придумайте любой пароль и добавьте в `.env.local` (и в Vercel):

```
ADMIN_PASSWORD=придуманный_пароль
```

Вход спрятан за копирайтом в футере сайта. Сессия хранится в браузере год —
спросит пароль один раз, дальше не будет. Кнопка «Забыть меня» в админке
сбрасывает сессию.

## 2. База данных

Уже подключена — бесплатный план Neon Postgres, установлен через Vercel
Marketplace прямо в этот проект. `DATABASE_URL` и другие переменные уже есть
в `.env.local` и в Vercel (появляются автоматически при подключении).

Если понадобится пересоздать таблицы (например, на новой базе или после
случайного удаления):

```bash
node scripts/init-db.mjs
```

Создаёт (если их ещё нет) две таблицы:
- **leads** — заявки с сайта (name, contact, niche, comment, created_at)
- **businesses** — найденные бизнесы (name, industry, city, address, card_url,
  whatsapp, score, qualified, created_at)

## 3. Как данные попадают в админку

- **Заявки с сайта** — автоматически, форма на сайте пишет прямо в базу.
- **Найденные бизнесы** — вручную запускаете конвейер:
  ```bash
  TWOGIS_API_KEY=... node scripts/fetch-leads-2gis.mjs "автосервис" "Алматы" data/leads.csv
  # проверяете верхние строки, копируете телефоны по card_url — см. LEAD_QUALIFICATION_FILTERS.md
  node scripts/score-leads.mjs data/leads.csv --push
  ```
  `--push` отправляет весь список (не только прошедших порог) в таблицу
  businesses — в админке сразу видно и балл, и кто прошёл (зелёным).
  `DATABASE_URL` для скриптов берётся из `.env.local`, если вы используете
  `dotenv` или подставляете переменную вручную перед командой (см. пример в
  `LEAD_QUALIFICATION_FILTERS.md`).

## 4. Открыть админку

`https://ваш-домен/admin` (или кликните по копирайту в футере сайта) →
введите пароль.

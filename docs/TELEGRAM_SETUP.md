# Настройка Telegram-бота (бесплатно)

Бот принимает сообщения от потенциальных клиентов, отвечает коротким приветствием
и пересылает их запрос вам, а вам в ответ приходит уведомление с контактом клиента.
Всё на бесплатном Telegram Bot API — платить не за что.

## 1. Создать бота

1. Откройте Telegram, найдите **@BotFather**.
2. Отправьте `/newbot`, следуйте подсказкам (имя бота и username, должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456:ABC-DEF...` — это `TELEGRAM_BOT_TOKEN`.

## 2. Узнать свой chat_id

1. Найдите в Telegram **@userinfobot** и напишите ему любое сообщение.
2. Он ответит вашим `Id` — это `TELEGRAM_CHAT_ID` (сюда будут приходить уведомления о лидах).

## 3. Заполнить .env.local

Скопируйте `.env.local.example` в `.env.local` и укажите:

```
TELEGRAM_BOT_TOKEN=полученный_токен
TELEGRAM_CHAT_ID=ваш_id
TELEGRAM_WEBHOOK_SECRET=любая-случайная-строка
```

`TELEGRAM_WEBHOOK_SECRET` — просто придуманная вами строка (например, набор случайных
символов), она защищает `/api/telegram/webhook` от посторонних запросов.

## 4. Задеплоить сайт

Бот принимает сообщения через вебхук, а значит сайт должен быть доступен по
публичному адресу (например, на Vercel — бесплатный план подходит). После
деплоя добавьте те же переменные окружения в настройках проекта на Vercel.

## 5. Подключить вебхук к боту

После деплоя выполните (замените токен, секрет и домен на свои):

```bash
curl -F "url=https://ваш-домен.vercel.app/api/telegram/webhook" \
     -F "secret_token=такой_же_как_TELEGRAM_WEBHOOK_SECRET" \
     https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook
```

Ответ должен быть `{"ok":true,"result":true,...}`.

## 6. Проверить

Напишите вашему боту в Telegram что угодно. Вы должны получить уведомление на
свой `TELEGRAM_CHAT_ID` с текстом клиента, а сам клиент — короткое подтверждение,
что его сообщение передано менеджеру.

Команда `/start` показывает клиенту приветствие с описанием услуг вместо
пересылки — используйте её как первое сообщение в ссылке `t.me/ваш_бот`.

## Локальная разработка (без деплоя)

Если хотите проверить бота локально до деплоя — используйте бесплатный туннель,
например [ngrok](https://ngrok.com/) (`ngrok http 3000`), и укажите его временный
адрес в `setWebhook` вместо домена Vercel.

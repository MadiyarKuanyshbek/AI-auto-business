# 20 фильтров квалификации бизнеса

Цель — не писать всем подряд, а сначала оценить, действительно ли бизнесу
нужна автоматизация. Собирайте эти данные вручную из бесплатных публичных
источников (2GIS, Google Maps, Instagram, сайт бизнеса) в таблицу — формат
описан в `scripts/score-leads.mjs`. Отправка сообщения — только вручную,
только тем, кто набрал проходной балл. Это сознательное решение: автоматическая
массовая рассылка через личные WhatsApp/Telegram банит номер и подпадает под
законы о спам-рассылках — риск того не стоит.

## Отсекающие фильтры (red flags — если да, не писать вообще)

1. Бизнес закрыт/приостановлен (по вывеске, отзывам, статусу в 2GIS).
2. Явно нет постоянного потока клиентов (разовые/проектные продажи, не запись).
3. Микро-бизнес без сотрудников и стабильного дохода (не осилит внедрение).
4. Уже пользуется похожим ИИ-администратором (видно по виджету на сайте/боту).
5. Enterprise 500+ сотрудников (другой цикл продаж — не для холодного контакта).

## Фильтры-баллы (каждый = +1, чем выше сумма, тем приоритетнее лид)

6. Работает 8+ часов в день или 24/7 (высокая нагрузка на приём заявок).
7. Есть выделенный администратор/ресепшн в штате (боль реальна и осознаётся).
8. Публичные отзывы упоминают «долго отвечают», «не дозвониться», «пропустили запись».
9. Рейтинг на картах 4.0+ (не токсичный бизнес, с которым приятно работать).
10. 20+ отзывов на 2GIS/Google Maps (стабильный поток клиентов).
11. Есть сайт или лендинг (уровень цифровой зрелости выше среднего).
12. Присутствует в 2+ каналах связи (телефон + WhatsApp/Instagram) — коммуникация фрагментирована.
13. Ведёт активную рекламу (готов тратить на рост, есть бюджет).
14. Активность в Instagram/2GIS за последние 30 дней (бизнес живой, не заброшенный).
15. Аккаунт в Instagram/Facebook показывает медленное время ответа в директ.
16. Отрасль входит в целевой список (СТО, салоны, клиники, отели, аренда недвижимости, IT/SaaS, ритейл, онлайн-школы, блогеры, медиа).
17. Есть доступное контактное лицо (владелец/директор, а не общий call-центр).
18. География совпадает с зоной, где вы можете обеспечить поддержку (город/часовой пояс).
19. Конкурент в той же нише уже использует автоматизацию (рынок готов, есть с чем сравнить).
20. Ещё не пользуется CRM/календарём для записи (проще продать решение «с нуля», нет миграции).

## Как использовать (автопоиск + ручная проверка + скоринг)

### 1. Получить бесплатный ключ 2GIS Catalog API

1. Зайдите на [dev.2gis.ru](https://dev.2gis.ru/) и зарегистрируйтесь (бесплатно, без карты).
2. Создайте приложение → скопируйте API-ключ.
3. Пропишите его в `.env.local`: `TWOGIS_API_KEY=ваш_ключ` (или передавайте прямо в команде, см. ниже).

Это официальный API для поиска организаций — то, для чего он создан. Не
скрапинг сайта, поэтому не блокируется и не нарушает правила 2GIS.

**Проверено на живом бесплатном ключе (2026-09):**
- лимит `page_size` — максимум **10** записей за один запрос (скрипт уже это учитывает);
- телефон и сайт (`contact_groups`) бесплатный тариф **не отдаёт** — это,
  похоже, платная часть API. Пока не оплатите более высокий тариф, номер
  телефона придётся брать вручную по прямой ссылке на карточку (см. ниже) —
  один клик, а не поиск по названию;
- лимит запросов в сутки/минуту 2GIS в личном кабинете не показывает явно —
  если увидите ошибку про превышение лимита, просто подождите и запустите
  скрипт снова с `--pages=1-2` за раз вместо большого объёма.

### 2. Найти бизнесы автоматически

Для одной ниши и города — как раньше:

```bash
TWOGIS_API_KEY=ваш_ключ node scripts/fetch-leads-2gis.mjs "автосервис" "Алматы" data/leads.csv
```

Для регулярного поиска сразу по нескольким нишам и городам за один запуск —
`find-clients.mjs`. Он ищет через тот же официальный API, но дополнительно:
не повторяет бизнесы, которые уже есть в базе (таблица `businesses`) — так
регулярные перезапуски не приводят к повторной ручной проверке одних и тех
же карточек — и делает паузу между запросами, чтобы бережно относиться к
бесплатному лимиту 2GIS.

```bash
TWOGIS_API_KEY=ваш_ключ DATABASE_URL=ваш_url node scripts/find-clients.mjs --cities="Алматы,Астана" --niches=auto,beauty,clinic --pages=2
```

- `--cities` — обязателен, через запятую.
- `--niches` — необязателен, по умолчанию ищет по всем нишам, для которых
  поиск по карте вообще имеет смысл (СТО, клиники, салоны, отели, аренда
  недвижимости, IT-компании, веб-студии, магазины, склады, школы). Полный
  список — в `QUERY_MAP` внутри скрипта. Блогеров/медиа/бренды 2GIS не
  найдёт — это не точки на карте, их ищут вручную в Instagram.
- `--pages` — страниц на каждую комбинацию ниша+город (по 10 бизнесов на
  страницу, лимит бесплатного тарифа).
- `DATABASE_URL` — не обязателен для самого поиска, но без него скрипт не
  сможет пропустить уже известные бизнесы.

Оба скрипта заполняют часть из 20 фильтров (рейтинг, число отзывов, отрасль,
гео) сразу, отсортировав самые перспективные (по рейтингу и отзывам) в
начало файла. Для каждого бизнеса есть колонка `card_url` — прямая ссылка на
карточку в 2GIS, где телефон открывается кнопкой «Показать телефоны».

### 3. Быстро проверить вручную только верхние строки

API не умеет определять часы работы, наличие ресепшена, жалобы в отзывах,
рекламу, наличие сайта и т.д. — переходите по `card_url` (или ищите в
Instagram) за ~30 секунд на бизнес и проставляете `1`/`0` в оставшихся
колонках, заодно копируете телефон в колонку `whatsapp`. Проверяйте не весь
список, а только верхние 10-20 строк — остальные и так вряд ли попадут в
порог.

### 4. Посчитать баллы и получить черновики сообщений

```bash
node scripts/score-leads.mjs data/leads.csv
```

Скрипт посчитает баллы, отсечёт red-flag записи и выведет отсортированный
список с готовым черновиком сообщения для каждого лида.

### 5. Отправить вручную

Только тем, кто прошёл порог, от своего аккаунта — это не спам, потому что
каждое сообщение адресное, осмысленное и отправлено человеком, а не ботом.
